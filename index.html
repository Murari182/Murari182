2. Enabling the Contribution Snake Workflow on GitHub 

1. Sync or push this repository to https://github.com/Murari182/Murari182 (main branch).
2. On GitHub, open Murari182/Murari182 -> Settings -> Actions -> General:
   Ensure "Read and write permissions" is enabled under Workflow permissions.
3. Go to the "Actions" tab -> select "Generate Contribution Snake" -> click "Run workflow".
   (Until you run it, README.md automatically uses the pre-seeded assets/github-snake-dark.svg and assets/github-snake.svg so there is never a broken image!)
