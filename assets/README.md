## ◈ Technical Architecture & Animation Mechanics

1. **Native SMIL & SVG Compatibility:**
   - Powered purely by `<animate>`, `<animateTransform>`, and `<animateMotion>`.
   - Zero runtime scripts; fully compliant with GitHub's Camo image sanitizer.
2. **High-DPI Clarity & Scaling:**
   - Standardized on wide aspect ratios (`920px` width) for responsive scaling across mobile and 4K displays.
3. **Typography & System Fallbacks:**
   - Web fonts (`Cinzel`, `JetBrains Mono`) backed by clean system fallbacks (`Georgia`, `Fira Code`, `monospace`).
