## ◈ Architectural Overview

This repository houses a dual-layer developer ecosystem:
1. **The Interactive Web Application:** A high-performance React + TypeScript + Vite application styled with Tailwind CSS, featuring living SVG animations, real-time GitHub telemetry, an interactive rocket streak trajectory, a chronological code snake automaton, a 365-day contribution universe heatmap, and a verified achievement constellation.
2. **The GitHub Profile README:** A luxury, editorial-grade GitHub profile README (`README.md`) powered by the custom animated vector hero banner (`assets/murari-header.svg`), verified portrait, typing animation, structured project cards, and activity stats that render seamlessly on GitHub's Camo proxy.

## ◈ Signature Interactive Visualizations

### 1. MISSION: CONSISTENCY 🚀
- **Purpose:** Represents the developer's coding journey as a space mission launch.
- **Visuals:** An animated climbing rocket ascending through 4 verified mission checkpoints with glowing engine exhaust plumes and trailing particle streams.
- **Controls:**
  - `ENGAGE THRUSTERS`: Toggles hyper-trajectory velocity and intensifies flame dynamics.
  - `MOTION TOGGLE`: Toggles standard smooth animation vs. reduced-motion mode.
- **Metrics Tracked:**
  - Current Streak (0 days active / grace period standby — calculated strictly from real consecutive days).
  - Longest Verified Streak (3 days).
  - 2026 Annual Velocity (110+ commits).
  - Total Recorded Contributions (129 commits).
  - Verified Active Days (32 days).
  - Latest Verified Activity Timestamp (2026-10-12).

### 2. THE CODE SNAKE 🐍
- **Purpose:** An algorithmic timeline automaton navigating across the chronological contribution matrix.
- **Visuals:** A segmented snake featuring a radiant head sensor and a rose-to-gold gradient body (`#E8B4CB` to `#D6A66D`). Cells illuminate dynamically as the automaton scans past verified commit dates.
- **Controls:**
  - `PAUSE / RESUME`: Halts or resumes automaton scanning.
  - `1x / 2x SPEED`: Toggles clock frequency.
  - `RESET`: Restarts path from initial chronocoordinate.

### 3. GITHUB CONTRIBUTION UNIVERSE 🌌
- **Purpose:** Comprehensive 365-day annual contribution heatmap.
- **Features:** 52 columns × 7 weekday rows with month headers and weekday indicators.
- **Interactivity:** Hovering or focusing on any coordinate displays an instant telemetry readout: exact date, weekday, commit volume, and velocity rating.
- **Filter:** Allows toggling between the complete annual matrix and active commit days only.

## ◈ Local Development & Testing

### 1. Start Development Server
```bash

```
Accessible at `http://localhost:5173/`.

### 2. Production Build
```bash
npm run build
```
Compiles TypeScript and creates optimized assets in `dist/`.

### 3. Preview Production Bundle
```bash

```
